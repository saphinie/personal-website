0 / 业务定位与机会

你刚完成自己的个人主页（3D 数字人 + 科技风 + 永久托管），这条链路本身就是产品。目标不是「再做一个网站」，而是把这条链路标准化成可复制的服务，向有个人品牌需求的人售卖。

  • 核心卖点：不是模板套站，而是「有记忆点的个人主页」——3D 数字人、动态科技感、极简编辑风等差异化视觉。
  • 市场空白：多数个人主页要么是简历 PDF，要么是千篇一律的模板站；「带 3D/动态交互 + 审美在线」的供给稀缺，尤其下沉到非技术人群（作家、设计师、咨询师）。
  • 已验证资产：你自己的上线站（https://saphinie.github.io/personal-website/）就是活样例 + 销售物料。
  • 一句话定位：「为每个人打造一个有记忆点的个人主页」 —— 个人品牌设计师 × AI 创作者 的人设天然契合。

3 / 技术架构与标准化（可复制的关键）

你之前是「一个站点手写一遍」。要接 10 款 + 持续接单，必须有骨架复用 + 主题切换机制，否则每单都从零写会亏死。

3.1 目录资产库

  • /core：共享骨架（base.css、nav、footer、滚动揭示、部署脚本）—— 一次写好，10 款复用。
  • /themes/01 ~ 10：每款一个主题包，只含「差异部分」：theme.css（色板/字体/Hero 形态）、hero.js（可选动效，如 3D/粒子/Lottie）。
  • /content：每个客户的 profile.json（姓名、定位、经历、作品、联系方式）—— 内容与样式解耦，换客户只填 JSON。
  • /modules：可插拔模块——3D 数字人、终端打字、计数动画、二维码分享、作品网格。按需组合。

3.2 主题切换原理

骨架读 profile.json 渲染内容，再按所选 theme.css 覆盖 CSS 变量（--bg / --accent / --font）。一套代码，10 张皮。

3.3 已验证可直接复用的模块

  • 3D 数字人（STYLE 01 核心，已跑通 Three.js CDN importmap）
  • 粒子星座背景（鼠标连线，科技风通用）
  • 终端打字板 / 数字计数 / 技能条（数据、科技风通用）
  • 本地生成二维码（避坑：别用 qrcode CDN，已踩过 404）

4 / 标准开发流程（7 步）

1
需求采集
客户填表：职业、定位、风格偏好（给 10 款预览选 1）、素材（照片/简历/作品图）。
2
选款与报价
按风格编号 + 模块组合出套餐价，签约收定金。
3
内容填充
把客户资料写成 profile.json，套进对应主题骨架。
4
风格微调
换色板/字体/动效强度，本地 server.js 预览确认。
5
交互增强（可选）
按需加 3D 数字人 / 终端 / 计数等模块。
6
部署上线
GitHub Pages（永久链接）或客户自有域名；生成分享海报 + 二维码。
7
交付与维护
交源码 + 操作说明；年维护套餐可选（内容更新、续托管）。

5 / 交付与部署体系

  • 托管：统一用 GitHub Pages（你已跑通，免费、永久、可绑域名）。每人一个仓库或子目录。
  • 避坑（来自你自己的教训）：绝不用 CloudStudio 临时链接做交付二维码——会失效。GitHub Pages 永久链接才是正解。
  • 分享物料：每单附一张带二维码的分享海报（本地生成 qr.png，不依赖 CDN）。
  • 客户自维护：交付一份「改文字/换图」图文说明（只动 profile.json 和资源文件夹），降低售后成本。

7 / 十款开发排期（先建资产库，再接单）

阶段 A：搭骨架（第 1–2 周）

  • 抽出 /core 共享骨架与可插拔模块（把蔡少华站的可复用部分剥离出来）
  • 定好 profile.json 字段规范与渲染逻辑

阶段 B：做 10 款主题包（第 3–6 周）

  • 每周完成 2–3 款，先易后难（极简/手作/商务 → 国风/数据 → 3D数字人/插画/Lottie）
  • 每款配套一张预览图 + 一句话卖点，作为销售货架

阶段 C：上线展示站（第 7 周）

  • 做一个「风格展厅」页，10 款可切换预览，挂你永久链接下当获客入口
  • 同步发公众号「人间句读」+ 朋友圈种草

8 / 风险与规避

⚠ 已知雷区（含你已踩过的）

  • 交付链接失效：只用 GitHub Pages 永久链接，绝不交付临时沙箱短链当二维码。
  • CDN 依赖翻车：二维码库、动效库尽量本地化或锁定版本；qrcode CDN 曾 404，已改本地生成。
  • 海报保存截断：html2canvas 不支持 aspect-ratio，海报用显式 height。
  • 每单从零写：不建骨架资产库就会越做越亏——先投 2 周搭 /core。
  • 售后无底洞：交付时附「自维护说明」，把小改动成本转移给客户。
  • 素材版权：字体/插画用可商用或自绘，避免侵权纠纷。

9 / 起步建议（下一步）
