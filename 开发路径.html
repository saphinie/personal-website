个人网站开发路径

从一份简历到带 3D 数字人的科技风主页 · 蔡少华（品牌策划人 × AI 创作者）

纯静态站点 HTML/CSS/JS Three.js 3D 数字人 GitHub Pages 托管 2026-09-09 起

Overview / 总览

  • 目标：把简历内容做成可对外展示的个人能力主页，要有记忆点
  • 记忆点：3D 数字人开场 + 深色霓虹科技风 + 参考 yucolab 的极简菜单
  • 技术栈：原生 HTML/CSS/JS，Three.js（CDN importmap），Node 本地预览
  • 最终成果：https://saphinie.github.io/personal-website/（永久链接）

Phases / 开发阶段

01需求与素材
明确目标，从简历里提取可展示内容
  • 读取简历 docx，提炼：品牌策划 10+ 年经历、AI 创作者新身份、项目作品清单
  • 参考站点：yucolab 顶部菜单（首页/关于/能力/作品/经历/联系）
  • 用户补充：提供真实照片，要求数字人「像自己」
产出：内容骨架 + 菜单结构 + portrait.jpg
02设计决策
定下视觉与交互方向，避免返工
  • 视觉风格：初选「浅色极简」→ 后按反馈升级为「深色霓虹科技风」
  • 数字人互动：文字气泡 + 打字机自我介绍（稳定、加载快）
  • 形象方案：先用程序生成动漫形象，后改为「用户照片全息化」
产出：配色（青 #35d6ff）、版式、交互脚本
03核心开发（首版）
搭出可运行的网站骨架
  • index.html：数字人开场 overlay + 吸附导航 + 6 个板块 + 浮动吉祥物
  • style.css：浅色极简 + 毛玻璃卡片 + 滚动揭示动画
  • main.js：Three.js 程序生成动漫数字人（挥手、打字机、进入主页）
  • server.js：Node 静态服务器（端口 4173）本地预览
技术：Three.js procedural mesh、IntersectionObserver
04形象与内容落地
把用户真实信息放进去
  • 「关于我」头像：从占位字换成本人照片
  • 右下角浮动按钮：换成照片头像，随时唤出数字人
  • 简历下载：docx 放入 assets/downloads 并提供按钮
涉及文件：portrait.jpg、index.html 头像区
05科技感升级（大改）
按反馈「动态内容太少、不够数字」做增强
  • 整体换深色霓虹主题，常驻粒子星座背景（鼠标连线）
  • 新增「数字工作台」仿终端打字板块（滚动自动打印命令）
  • 首页数字计数动画、技能条滚动填充、卡片 3D 倾斜
  • 开场数字人改为照片全息化（扫描线 + 光环 + 粒子 + 扫描光带）
重写 index.html / style.css / main.js
06部署与分享
让别人能访问，并能扫码分享
  • CloudStudio 临时部署（教训：链接会失效，不适合长期）
  • 制作分享海报 poster.html + 二维码（本地生成 qr.png，不依赖 CDN）
  • 改用 GitHub Pages 正式托管，得到永久链接
  • 用永久链接重新生成二维码并更新海报
部署：GitHub REST API 建仓/推送/开 Pages；二维码本地生成

Pitfalls / 踩过的坑与解决

⚠ 关键问题记录

二维码库 CDN 404 → qrcode@1.5.3 的 CDN 路径失效，改用本地 Node 生成 qr.png，不再依赖运行时 CDN。
海报保存被截断 → html2canvas 对 CSS aspect-ratio 支持差，克隆高度算错；改为显式 height:720px 解决。
扫码显示「链接失效」 → CloudStudio 沙箱短链过期；改用 GitHub Pages 永久链接，二维码重做。
GitHub 令牌暴露 → 用户在聊天里粘贴 classic PAT；已用完即清，需去 Settings→Tokens 手动吊销。
git push 连接重置 → 网络抖动，重试 + 用 token 内嵌 URL 推送成功，事后把 remote 改回无令牌地址。
